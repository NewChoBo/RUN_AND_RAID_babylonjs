# RUN AND RAID · Babylon.js

브라우저에서 실행하는 런앤레이드 전용 프로젝트입니다. 기존 2대2 화물 추격 경기, 영웅 선택, 봇 연습, 터치 조준과 온라인 방 코드를 포함합니다.

[공개 게임](https://newchobo.github.io/RUN_AND_RAID_babylonjs/)에서 **게임시작 → 빠른 매칭**을 누르면 현재 참가 인원을 보며 기다립니다. 네 명이 모이면 모두의 캐릭터 선택창이 열리고 장비 프리셋을 설정할 수 있습니다. 경기 시작 전에 누군가 나가면 남은 참가자는 다시 매칭을 기다립니다. 친구와 플레이할 때는 **사설방 → 방 만들기**로 방 코드를 공유하고, 상대는 **참가하기**에서 코드를 입력합니다. 사설방에 혼자 있으면 주자와 스킨을 고르고 봇전을 시작할 수 있습니다. 네트워크 연결 없이 연습하려면 **사설방 → 오프라인 봇 연습**을 선택합니다. 원작 공략의 17명, 원본 모델에 임시 스킬을 연결한 13명, 기존 연습 주자 3명을 선택할 수 있습니다. 픽창에서 고른 **출전 스킨**은 팀 좌석 일러스트와 경기 모델에 함께 적용됩니다. 스킨과 연결되지 않은 모델은 상점 감상실에서 볼 수 있습니다. [캐릭터별 복원·창작 기록](docs/ORIGINAL-ROSTER.md)

[원작 운영진 자료집](docs/OFFICIAL-GUIDE.md)에서 당시 픽창·상점·전장 화면과 경기 규칙, 장비·캐릭터 능력치를 볼 수 있습니다. [케이론 왕국 설정집](docs/WORLD.md)에는 공식 지도와 캐릭터 단편 네 편의 인물 관계가 정리되어 있습니다. 픽창에서는 주자를 고르고 **원작 스킬표**를 펼치면 당시 기술 순서를 확인할 수 있습니다.

당시 플레이 경험으로 점프 중 평타, 분노, 빠른 시전, 보스 패턴을 확인할 때는 [원작 플레이 확인 질문](docs/ORIGINAL-QUESTIONS.md)을 참고하세요.

## 실행

Node.js 22.12 이상에서 프로젝트 루트에서 실행합니다.

```sh
npm ci
npm run dev
```

브라우저에서 http://127.0.0.1:5198/ 을 엽니다. 봇 연습은 오프라인으로 실행할 수 있습니다. 온라인 경기는 프로젝트 루트의 `.env.local`에 이 프로젝트의 `VITE_PHOTON_APP_ID`를 설정한 뒤 서버를 다시 시작합니다.

```sh
npm run check
npm test
npm run build
```

## UI 수정

로비 톱니바퀴와 경기 일시정지 메뉴의 **설정**에서 전체 화면을 켜거나 끌 수 있습니다. 작은 화면에서 경기 진입이 어려우면 화면 크기 안내창에서도 전체 화면을 요청할 수 있습니다.

표시 언어는 **설정 → 언어**에서 한국어와 English 중 선택합니다. 첫 방문은 한국어이며, 선택은 이 브라우저에 저장됩니다. 대기실과 경기에서 선택한 언어는 로비로 돌아갈 때 적용됩니다. 메뉴와 경기 안내에 사용하는 번역은 `src/content/locales/`에서 관리합니다. 개발일지 글과 원작 작품 제목은 원문으로 표시합니다.

로비 홈, 상점, 경기 대기실, 원작 에셋 화면의 마크업은 `src/ui/templates/`에 있습니다. 공통 상단 메뉴는 `toolbar.html`, 메뉴 아이콘은 `toolbar-icons.html`에서 수정합니다. 화면 동작은 `src/app/`, 스타일은 `src/ui/styles/`, 화면 전환은 `src/routes.ts`에서 관리합니다.

`index.html`에는 시작 화면, 게임 캔버스, 공통 대화상자와 각 템플릿의 위치가 있습니다. 예를 들어 `<!-- ui: shop -->` 위치에 Vite가 `shop.html`을 넣습니다. 개발 서버와 배포 빌드 모두 완성된 HTML을 브라우저에 전달하며, 템플릿 안의 이미지 경로는 `index.html` 기준으로 작성합니다.

## 게임 구현과 에셋

경기 구현은 [기존 웹판의 3fcadc2](https://github.com/NewChoBo/oblivion-archive/tree/3fcadc2)에서 이식했습니다. 게임 규칙은 `src/game/raid`, 영웅별 콘텐츠는 `src/content/raid`, Babylon.js 렌더링은 `src/platform/babylon/raid`에 있습니다. 기본 플레이 모델과 파티클 출처는 [에셋 출처](docs/ASSETS.md)에 기록했습니다.

개발진 제공 Player.zip의 전체 변환과 원작 모션 준비 절차는 [Player 에셋 준비](docs/PLAYER-ASSETS.md)에 있습니다.

원본을 준비하면 [에셋 열람 화면](http://127.0.0.1:5198/#/assets)에서 캐릭터나 파일명으로 찾아 모델을 회전하고 변환 파일을 내려받을 수 있습니다.

공개 플레이판 배포, Photon 연결 검증, 이어서 지킬 전투 규칙은 [전용 프로젝트 인계 가이드](docs/HANDOFF.md)에 정리했습니다.
