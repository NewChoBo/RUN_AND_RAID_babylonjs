# Blender에서 원본 피벗과 헬퍼 편집하기

Blender 5.3에서 원본 MAX의 노드 위치·방향·크기를 애니메이션이 있는 Empty로 불러올 수 있다. 원래 캐릭터의 리그 옆에서 손이나 무기의 피벗을 확인하거나, 그래프 에디터에서 노드의 키를 편집할 때 사용한다.

1. 원하는 그룹의 원본 데이터 ZIP을 풀어 `native-edit/`과 `native/`가 같은 폴더 아래에 있도록 둔다. 공통 `Blender-tools.zip`도 풀어 둔다.
2. `native-edit/<그룹>.blend`를 열고 상단 Scene 목록에서 원하는 원본 장면을 고른다.
3. Blender의 **Text Editor → Open**에서 공통 도구의 `import_max_pivots.py`를 연다. **Run Script**를 누르면 현재 장면에 `Max pivots - <장면 이름>` 컬렉션이 생긴다.
4. 타임라인을 재생하거나 Empty를 선택해 Transform과 Graph Editor의 애니메이션 곡선을 편집한다. **Save As**로 작업본을 저장한다. 저장한 피벗 키는 다른 폴더로 옮겨도 재생된다.

움직이는 캐릭터의 손·무기와 원본 피벗을 겹쳐 보려면 같은 그룹의 Blender 작업본 ZIP과 원본 데이터 ZIP을 같은 최상위 폴더에 푼다. `blend/<그룹>/` 아래 원하는 애니메이션의 개별 `.blend`를 열고 같은 스크립트를 실행한다.

스크립트는 장면의 원본 SHA-256을 읽어 대응하는 파일을 찾는다. 이미 풀어 둔 그룹에도 공통 스크립트를 바로 사용할 수 있다. 같은 장면에서 다시 실행하면 먼저 가져온 컬렉션을 사용한다. Blender 기본 보안 설정에서 사용자가 **Run Script**를 누를 때 실행된다.

## 원본 행렬을 옮기는 방식

`native/scenes/<SHA-256>.f32.gz`에는 첫 프레임부터 마지막 프레임까지, 원본 노드 순서대로 프레임·노드당 float32 12개가 little-endian으로 들어 있다. 앞의 세 행은 Max의 월드 기준 축, 마지막 행은 피벗의 월드 위치다. 두 프로그램은 모두 Z-up이다. 도구는 기저 행렬을 전치하고 Max 시스템 단위와 Blender 장면 단위를 적용해 위치를 환산한다.

부모를 식별할 수 있으면 월드 행렬에서 로컬 변환을 계산해 원본 부모·자식 관계를 만든다. 같은 이름의 부모가 둘 이상이거나 특정 프레임에 부모 스케일이 0이라 역행렬을 구할 수 없으면 해당 노드는 월드 좌표로 재생하고 원래 부모 이름을 사용자 속성에 기록한다. 피벗 Empty의 `max_node_name`, `max_node_handle`, `max_parent_name`에서 원본 노드를 찾을 수 있다.

축이 반전된 장면은 부호 있는 스케일을 유지한다. 축이 기울어지는 전단 변형(shear)은 회전·스케일용 부모와 회전용 자식 Empty로 나누어 표현한다. 이 경우 최종 위치와 방향은 이름이 `- pivot`으로 끝나는 자식을 보면 된다. 원래 행렬의 축·스케일 분해와 Blender 채널의 숫자는 달라도 두 Empty를 합성한 월드 변환을 원본 프레임과 비교할 수 있다.

키는 Max에서 샘플링한 정수 프레임에 놓인다. 프레임 사이에는 Blender의 선형 키 보간을 사용한다. 원본 Biped/IK 컨트롤러의 편집 동작과 서브프레임 곡선을 확인할 때는 함께 보관한 MAX와 BIP를 사용한다.
