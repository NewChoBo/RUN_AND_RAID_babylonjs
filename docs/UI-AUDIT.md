# 화면별 UI와 아이콘 점검

2026년 11월 28일. 원작 대기실의 오른쪽 도구 열, 화면 중앙의 픽창, 경기 우상단 톱니와 상단 개인 전적을 기준으로 현재 게임을 점검했다. 서로 다른 화면이 같은 기호를 쓰면서도 각 화면의 원작 구성을 유지하는 데 중점을 뒀다. [원작 화면 대조](OFFICIAL-GUIDE.md)

## 화면별 결과

| 화면                | 점검한 조작과 결과                                                                                                                                                                                                                                                                                                                                                           |
| ------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 타이틀·로딩         | 시작, 입장 취소, 로딩 상태, 팁, 모듈 로딩 실패 시 재시도 경로를 점검했다. 바깥 프레임이 확보한 노치 여백은 로딩 화면 안에서 다시 더하지 않는다.                                                                                                                                                                                                                              |
| 로비                | 홈·상점·장비·내정보·랭킹, 시작, 재화, 알림·친구·채팅·설정, 카페 링크와 개발일지를 확인했다. 시작은 좌우 열 사이 정중앙에 놓인다. 설정은 맨 오른쪽에 고정한다. 낮은 가로 터치 화면에서는 채팅을 톱니 왼쪽에 두고, 높이가 충분하면 원작처럼 아래에 둔다. 골드·블루다이스 잔액 두 줄은 같은 재화 안내 버튼 안에 표시한다. 장비·내정보·랭킹·알림·친구·재화는 미구현 안내를 연다. |
| 공통 설정·모드 선택 | 닫기와 제목에 같은 헤더를 쓴다. 음량, 음소거, 그래픽 등급 양끝, 언어, 전체 화면, 빠른 매칭 취소와 사설방 생성·퇴장을 확인했다. 음소거와 음량 조절은 각각 별도의 입력이다.                                                                                                                                                                                                    |
| 대기실·픽·채팅      | 5:3 비율은 대기실 콘텐츠에 적용한다. 툴바는 로비와 같은 위치에 둔다. 좌석, 초상, 사용 중 표시, 팀 색, 남은 시간, 준비·확정, 팀 채팅과 빠른 문구를 확인했다.                                                                                                                                                                                                                  |
| 스킬·스킨·장비      | 세 기본 스킬의 등급 조절, 리셋, 스킨 및 효과 선택, 장비 네 칸을 점검했다. 영문 등급 버튼과 상세 안내는 전투에서 쓰는 영문 스킬명을 쓴다. 공식 기술표에는 한국어 원문이 남는다.                                                                                                                                                                                               |
| 상점·감상실         | 일러스트와 모델 전환, 캐릭터 선택, 모델 회전·확대, 목록과 스킨 선택을 점검했다. 처음 진입했을 때 동작을 연결한 다음 버튼을 활성화한다. 선택창 헤더를 매칭·설정과 통일했다.                                                                                                                                                                                                   |
| 원본 에셋 탐색기    | `library.html` 직접 진입, 뒤로가기, 검색·그룹·파일 선택을 점검했다. 모바일에서 검색 칸에 포커스를 줘도 툴바 위치가 유지된다. 로컬에서는 준비된 원본 카탈로그를 사용하며, 공개판에서는 원본 준비 안내가 뜬다.                                                                                                                                                                 |
| 전투 HUD·핑         | 점수·시계·개인 전적, 체력·분노, 걷기·점프, 스킬·조준·쿨타임, 팀 핑과 우상단 설정을 점검했다. 개인 처치·사망·도움에 검·해골·주먹을 붙였다. 핑은 드래그와 키보드를 지원하며 공격 대상에는 픽창과 같은 얼굴 크롭을 쓴다.                                                                                                                                                        |
| 전투 설정·결과      | 일시정지, 추가 설정, 재개, HUD 여백·스킬 크기, 미구현 항복, 결과 배너·기록표·로비 복귀를 점검했다. 결과표는 상대 진영에서 시작해도 자신이 속한 팀의 색·이름·수치가 일치한다.                                                                                                                                                                                                 |

## 위치와 터치 검증

- 740×360에서 대기실의 설정·채팅은 각각 26×21px였다. 수정 후 두 버튼 모두 44×50px이며, 스킬 등급 버튼은 44×26px에서 44×44px로 바뀌었다.
- 844×390에 왼쪽 36px, 오른쪽 24px, 아래 12px 노치를 적용했다. 왼쪽 이동 패드는 화면 x=72에서 46으로, 오른쪽 점프 버튼 여백은 48에서 34px로 바뀌었다. 각각 노치 안쪽에 10px의 조작 여백이 남는다. 사용자 HUD 여백을 24px로 올리면 양쪽 버튼이 정확히 24px 더 들어간다.
- 설정·매칭·상점 캐릭터 선택창의 제목은 각각 가로 중앙과 일치했다. 세 닫기 버튼은 모두 44×44px이며 가운데와 네 모서리가 같은 버튼을 가리켰다. 전투 톱니는 화면 크기와 설정에 관계없이 44×44px의 터치 영역을 사용한다. 667×375에서 스킬 140%, HUD 여백 24px일 때도 점수판과 4px 간격이 남았다.
- Chromium에서 740×360, 844×390, 1280×720의 한국어와 영어로 로비·감상실 경로와 픽·봇전·결과 경로를 실행했다. 터치·노치는 브라우저에서 재현했다. 물리 기기의 화면 회전, iOS Safari 주소창과 가상 키보드는 별도 확인 대상이다.

## 공통 컴포넌트

| 단위          | 사용 위치와 수정 방법                                                                                                                                                                                                                                                                  |
| ------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 아이콘과 버튼 | 메뉴·설정·내비게이션·개인 전적용 [SVG 심볼 25개](../src/ui/templates/ui-icons.html)는 첫 HTML에 한 번 들어간다. 동적 화면은 [uiIcon과 setButtonIcon](../src/ui/icons.ts)을 쓴다. 그림은 장식으로 처리하고 버튼이 번역된 이름과 동작을 갖는다. 아이콘 크기와 터치 영역은 따로 조절한다. |
| 일반 대화상자 | [ui-dialog와 ui-dialog-header](../src/ui/styles/dialog.css)는 매칭·공통 설정·상점 선택창의 가운데 제목, 오른쪽 닫기, 배경을 공유한다. 경기 설정에는 추가 설정과 재개가 따로 있고, 픽창과 결과표에는 전용 배치를 쓴다.                                                                  |
| 설정과 얼굴   | 로비와 전투에서 같은 [음향·그래픽 설정](../src/ui/battle-settings.ts)을 쓴다. [얼굴 크롭](../src/ui/raid-pick-face.ts)은 픽 목록·적 지정 핑·결과표에서 공유한다.                                                                                                                       |
| 안전영역      | [공통 여백](../src/ui/styles/shell.css)은 일반 페이지에서 브라우저 값을 읽는다. 모바일은 바깥 프레임이 안전영역을 먼저 확보하므로 자식 게임 화면의 안전영역은 0이다. 사용자 HUD 여백은 그 안쪽에 더한다.                                                                               |

원작 17명의 기술 아이콘 89개를 원격 주소에서 직접 받아 모두 96×96 PNG로 디코딩했다. 픽 얼굴 원화 17개와 장비 아이콘 8개도 열렸다. 로컬 대체 이미지인 기본 초상 33개, 얼굴 크롭 13개, 스킨 미리보기 37개의 WebP 파일을 검사했다. 매그너스의 태세 전환을 포함한 기술 슬롯과 아이콘 순서는 자동 테스트로 확인한다. [에셋별 출처와 매핑](ASSETS.md)
