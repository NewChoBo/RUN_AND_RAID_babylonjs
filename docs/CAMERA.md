# 원작 영상 기준 추격 카메라와 도로

## 비교 기준

조준 UI가 열린 장면과 영상 바깥의 휴대폰 내비게이션 바를 제외했다. 아래 좌표는 영상 파일의 왼쪽 위가 원점이다. 게임 화면 높이로 나누기 전에 위쪽 검은 띠를 뺀다. 소실점은 양쪽 난간 직선들의 연장선이 모이는 높이, 주자 기준점은 내 캐릭터의 녹색 발밑 링 중심이다. 링 외경은 가로 방향으로 읽었다.

| 영상과 시점                                                            | 게임 화면 세로 범위(px, 끝 제외) | 난간 소실점 y | 링 중심 y | 링 폭 |
| ---------------------------------------------------------------------- | -------------------------------- | ------------: | --------: | ----: |
| [카이켄 0:04.8](https://www.youtube.com/watch?v=eLLz8hqIJwU&t=4s)      | 0–480                            |           144 |    약 343 | 약 49 |
| [스위프트 3:24.75](https://www.youtube.com/watch?v=jSlFzUSup7s&t=204s) | 16–720                           |           251 |    약 552 | 약 75 |
| [릴딘 1:22](https://www.youtube.com/watch?v=RggZbGW3Aao&t=82s)         | 5–720                            |           206 |    약 491 | 약 68 |

소실점은 게임 화면 위에서 28~33%, 링 중심은 68~76%, 링 폭은 화면 높이의 9.5~10.7%다. 도로 폭은 스위프트 프레임에서 마주 보는 기둥 밑동을 약 490px 폭, y=355~365로 읽고 주자 깊이로 외삽했다. 폭은 대략 490 × (552−251)/(355~365−251), 즉 화면 높이의 1.84~2.02배다. 난간 두께, 바닥 접점의 그림자, 경사에 민감한 추정이다.

## 플레이판에 적용한 값

수직 시야각 0.94rad와 주자 링 외경 0.9375 게임 단위를 고정하고, 기본 추격 시 소실점 31%, 링 중심 72%, 링 폭 10.4%에 맞췄다. 도로 가장자리 안쪽 간격은 주자 깊이에서 화면 높이의 약 1.91배다. 아래 거리는 게임 좌표계의 값이다. 원작 카메라의 렌즈 정보나 미터 환산값은 확인되지 않았다.

| 항목                                        |       변경 전 |       변경 후 |
| ------------------------------------------- | ------------: | ------------: |
| 카메라 하향각                               |         15.6° |         10.9° |
| 주자 지면 기준 카메라 높이 / 수평 후방 거리 |  6.30 / 10.50 |   3.63 / 8.34 |
| 소실점 / 링 중심 (화면 높이 기준)           | 22.5% / 77.0% | 31.0% / 72.0% |
| 링 외경 / 화면 높이                         |          7.8% |         10.4% |
| 렌더링 도로 폭                              |            14 |            18 |

조준 시 링이 기본 폭의 약 70%(방향·지점) 또는 50%(대상)가 되도록 후방 이동량도 환산했다. 같은 카메라를 사용하는 타깃 시야 판정이 달라져 온라인 매칭 버전을 갱신했다.

카이켄의 원작 출발 화면에서는 마차가 현 플레이판보다 작고, 달리는 캐릭터가 정적 GLB보다 크게 보인다. 마차 크기와 출발 간격을 분리하려면 같은 마차가 여러 깊이에서 보이는 연속 프레임이 필요하다. 좌우 이동 한계, 종방향 경기 거리와 맵 전체 길이는 이번 실측 범위 밖이다.
